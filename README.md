# CRM-система

Веб-приложение для учёта услуг, рекламных кампаний, потенциальных и активных клиентов, а также контрактов.

## Возможности

- Авторизация на стандартных средствах Django.
- Разделы услуг, кампаний, лидов, контрактов и активных клиентов.
- Перевод лида в активного клиента из списка лидов.
- Роли: Оператор, Маркетолог и Менеджер. Пользователей и роли назначает администратор через `/admin/`.
- Статистика кампаний: количество лидов, активных клиентов и отношение дохода по контрактам к рекламному бюджету.
- PostgreSQL и Docker Compose.

## Запуск

```powershell
docker compose up --build
```

После запуска приложение доступно по адресу `http://localhost:8001/accounts/login/`.

Создайте администратора в отдельном терминале:

```powershell
docker compose exec web python manage.py createsuperuser
```

Войдите в `/admin/`, создайте пользователей и добавьте их в нужные группы. Группы создаются автоматически при запуске контейнера.

## Проверка

```powershell
docker compose exec web python manage.py test
docker compose exec web pylint --rcfile .pylintrc products ads leads contracts customers users crm
```
